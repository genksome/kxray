# kxray

Kernel offset extraction tool for Android boot images.

kxray parses boot.img, extracts the kernel, finds BTF metadata inside it,
and generates a C header (offsets.h) with struct field offsets needed
for kernel exploitation.

## Features

- Parses Android boot images (header v0 to v4)
- Extracts kernel and ramdisk from boot.img
- Auto-decompresses kernel and ramdisk
  (gzip, bzip2, lzma, xz, zstd, lz4)
- Handles padded kernel blobs (finds compression magic at any offset)
- Handles gzip streams with partial trailing data
- Scans the raw kernel for BTF metadata
- Parses BTF types, structs, and field offsets
- Shows any struct with all its fields and offsets
- Exports offsets.h with structs used in kernel exploits
- Built-in presets for common kernel exploitation tasks
- Custom preset: enter struct names manually
- Extracts kernel version and vermagic from the raw kernel
- Russian and English interface
- Colored output for readability

## Presets

kxray can generate offsets.h for specific tasks:

1. Minimal - base exploit (task_struct, cred, seccomp, pipe_buffer)
2. Full - all structs available in BTF
3. SELinux bypass
4. DEFEX bypass
5. KDP bypass
6. Knox bypass
7. Seccomp bypass
8. Pipe physrw
9. UMH / workqueue
10. filp root
11. Custom - your own structs

Custom syntax:

    task_struct
    cred:uid,gid,security
    task_struct,cred,pipe_buffer

## Requirements

- Python 3.8 or newer

Optional:
- lz4 for LZ4-compressed kernels
- zstandard for ZSTD-compressed kernels

Install optional dependencies:

    pip install -r requirements.txt

## Usage

    python3 kxray.py

Menu:

    1. Open file
    2. Analyze
    3. Extract
    4. BTF structs
    5. Export offsets.h
    6. Settings
    0. Exit

Typical workflow:

1. Open boot.img
2. Extract kernel and ramdisk
3. Show BTF structs or find a specific struct
4. Export offsets.h with the preset you need

## Project layout

    kxray.py            entry point
    kxray/
      bootimg.py        boot.img parser
      btf.py            BTF parser
      cli.py            menu and commands
      decompress.py     decompression handlers
      i18n.py           translations
      log.py            colored logging
      magic.py          magic word detection
      offsets.py        offsets.h generation and presets
      utils.py          helpers

## How it works

1. bootimg.py reads the Android boot image header, locates the kernel
   blob, and extracts it.
2. decompress.py detects compression at the start of the blob, or scans
   for a compression magic at any offset (handles padding before gzip,
   lz4, or other formats).
3. btf.py scans the decompressed kernel for the BTF section, parses the
   header, types, and strings.
4. offsets.py looks up structs and fields, applies the selected preset,
   and writes them as #define entries.
5. cli.py ties everything together with a menu.

## Notes

- Generated offsets depend on the exact kernel build. Always use a
  boot.img that matches the target device.
- BTF must be present in the kernel. If the kernel was built without
  CONFIG_DEBUG_INFO_BTF, kxray cannot extract struct offsets from it.
- Ramdisk extraction and decompression work on most formats, but some
  vendor-specific ramdisk layouts may need manual handling.
